# Changelog

## v0.2 — 2026-11-04

- Revised model for the OPPO Reno3 Vitality (Reno3 元气版).
- Raised acrylic plate's nominal bottom-edge height from 10 mm to 18 mm.
- Kept 100/150 mm sheet sizes and 2/3 mm thickness options.
- Added horizontal/vertical position adjustment, rotation, mirror and zoom to the optical test player.
- Included printable STL models, parametric CAD source, validation scripts and open-source release documentation.

**Status:** CAD/STL validation complete; 3D print assembly and optics not verified physically.
